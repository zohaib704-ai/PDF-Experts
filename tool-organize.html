      Visual page reordering that stays private

      Organize PDF renders each page as a small thumbnail using pdf.js, the same open-source library Firefox uses to display PDFs. You can then rearrange pages with drag and drop (on a desktop) or with the up and down arrow buttons (on any device). Deleted pages are marked with a strike-through, and can be restored before you rebuild the file.

      When you click Rebuild PDF, a new document is created that only contains the pages you kept, in the exact order you set. All work stays on your machine — thumbnails are drawn on a canvas and the final PDF is produced from the original file already in memory.

      Common uses

      • Move a cover page or table of contents to the front.
      • Remove duplicate pages from a scanned report.
      • Reorder chapters you received as a single export.
      • Trim blank pages before sending a PDF for print.
