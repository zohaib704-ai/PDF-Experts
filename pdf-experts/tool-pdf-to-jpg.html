      PDF to JPG, made simple

      PDF pages are a mix of text and vector graphics. To turn them into an image, the browser must "rasterize" the page — draw it onto a canvas and then read that canvas as pixels. PDF Experts uses pdf.js, the same library Firefox uses to display PDFs, to render each page at your chosen resolution before exporting.

      JPG is best when file size matters and you can tolerate very small quality loss. PNG is lossless and works better for line drawings, diagrams and text-heavy pages. Resolution 2× is a good default for slides and web use; 3× is what you want for print or retina screens.

      Practical uses

      • Turn a PDF slide deck into image thumbnails for a CMS.
      • Export a signed page as a JPG for a client's records.
      • Send a photo of a document that must not be edited.
      • Feed pages into an app that only accepts image files.

      To go the other way, use JPG to PDF.
