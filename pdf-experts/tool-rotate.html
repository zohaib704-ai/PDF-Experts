      Rotate PDF pages without losing quality

      The Rotate PDF tool changes the rotation attribute stored inside each PDF page. That means the document is not re-rendered or re-compressed, so there is no quality loss: text stays text, images stay sharp, and fonts stay embedded. Rotating pages is non-destructive in every viewer that respects the rotation flag.

      Use "All pages" for a scan that was saved sideways. Use "Selected pages" when only some pages came out of the scanner the wrong way — for example, a mixed document where the signature page is upside down but the rest is fine. Page numbers start at 1 in the file order you see in your PDF reader.

      What to know

      • Rotations are cumulative. Rotating 90° twice gives 180°.
      • If the source file uses landscape pages with pre-rotated content, use 90° or 270° rather than 180°.
      • To reorder pages afterwards, use Organize PDF.
