      How merging works in PDF Experts

      The Merge PDF tool loads each PDF you add into your browser's memory using a small WebAssembly-free JavaScript library. Every page is copied into a brand new document, in the order you choose, and the result is saved back to your disk. Because nothing leaves the page, the tool works offline once it has loaded and never sends a request containing your files.

      You can reorder files with the up and down arrows in the file list before merging. If a PDF is password-protected or corrupted, the tool skips it and shows you a clear error instead of failing silently. Page numbers from the source documents are preserved unless you use the Page Numbers tool first to normalise them.

      When to use Merge PDF

      • Combine a signed contract, an appendix and an invoice into a single PDF.
      • Join weekly reports into a monthly document.
      • Assemble scanned pages from separate PDFs into one submission.
      • Prepare a portfolio from several smaller exports.

      If your PDFs contain mixed page orientations, the merged file will keep each page in its own orientation. To standardise orientation first, rotate pages with the Rotate PDF tool before merging.
