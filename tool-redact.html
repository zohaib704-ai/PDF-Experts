      True redaction, not just black rectangles

      Many PDF tools draw a black rectangle over text but keep the text in the file — anyone can select and copy it. This tool renders each page as an image first, then draws the black boxes into the image, then rebuilds the PDF from those images. The hidden content is gone.

      Use this for contracts, court filings, IDs, medical records — any document where the redacted content must actually disappear.
