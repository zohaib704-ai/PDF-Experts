      What the report shows

      Compare PDF extracts the text from both files, aligns pages by number, and compares them word-by-word. Pages that are identical are skipped. For each page that differs, you see:

      • The page number that changed.
      • Words that appear only in version A.
      • Words that appear only in version B.
      • A note when the words match but the order changed.

      The output is a Markdown file you can open in any text editor, paste into a bug tracker, or attach to an email.

      Best for

      • Reviewing contract revisions.
      • Spotting changes between document versions.
      • Confirming that a translated PDF matches the source.
      • Checking that a redacted PDF has no leftover text.

      Note: the comparison is text-based, so it won't catch image-only changes. For a visual diff, wait for our upcoming Image Compare tool.
